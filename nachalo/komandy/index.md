## Общение

| Команда | Что делает |
| --- | --- |
| `/msg`, `/r` | Личные сообщения |
| `/ignore <ник>` | Не получать личные сообщения от игрока |
| `/msgtoogle` | Выключить личные сообщения |
| `/chatsettings` | Настройки чата: смерти, заходы, достижения, локальный, глобальный и чат фракции |
| `/ad` | Объявление на весь сервер, раз в 20 минут |
| `/voice` | Озвучка чата, с LITE |

## Фракции

| Команда | Что делает |
| --- | --- |
| `/faction` | Меню фракции: состав, территория, войны, смена стороны |
| `/election` | Выборы президента фракции |
| `/war` | Войны фракций, для президента и заместителя |
| `/fc` | Включить чат фракции |
| `/fc <текст>` | Одно сообщение своей фракции |

## Администрация

| Команда | Что делает |
| --- | --- |
| `/admins` | Вызвать администрацию |
| `/staff` | Кто из администрации в сети |

## Предметы и персонаж

| Команда | Что делает |
| --- | --- |
| `/renameitem` | Переименовать предмет в руке |
| `/autograph` | Оставить автограф на предмете |
| `/autograph remove` | Снять свой автограф |
| `/anon` | Подписать книгу как неизвестный |
| `/description` | Описание персонажа, видно по ПКМ |
| `/armorhide` | Скрыть свою броню от других игроков |
| `/resourcepack` | Включить пак KSEPSP |
| `/premium <пароль> confirm` | Вход без пароля для лицензии |

## Статистика

| Команда | Что делает |
| --- | --- |
| `/stats` | Убийства, смерти, первый заход, число заходов |
| `/playtime` | Наигранное время |
| `/online seen <ник>` | Когда игрок был в сети |
| `/online top` | Топ по наигранному времени |
| `/afktop` | Топ по времени в АФК |
| `/ogonok` | Серия ежедневных входов |
| `/ogonoktop` | Топ серий |
| `/number` | Цифры и кейсы |

## Жители

| Команда | Что делает |
| --- | --- |
| `/optimizevillagers <радиус>` | Отключить жителям ИИ, до 100 блоков, раз в 10 минут |
| `/unoptimizevillagers <радиус>` | Вернуть жителям ИИ |

## Донат

| Команда | Что делает |
| --- | --- |
| `/donate` | Подписка, титул, цвет ника, входы и выходы, QQ, кейсы, шапки |
| `/setmsg join`, `/setmsg exit` | Сообщения входа и выхода |
| `/hat` | Надеть предмет на голову |
| `/sign` | Подписать предмет |
| `/disc` | Свои пластинки |
| `@here` | Пинг всех игроков в чате |

## Отыгрыш

| Команда | Что делает |
| --- | --- |
| `/me` | Действие от первого лица |
| `/do` | Действие от третьего лица |
| `/try` | Попытка со случайным исходом |
| `/bones` | Бросить кость |
| `/coin` | Подбросить монетку |
| `/spit` | Плюнуть |

## Брак и позы

| `/sit`, `/lay`, `/crawl`, `/spin`, `/bellyflop` | Позы |
